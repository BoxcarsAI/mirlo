# Install Merlo (Unpacked)

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked**.
4. Select the `src` folder inside this repo.
5. Visit a page like a news site and confirm highlights appear.

## What to Expect

- The first 5 occurrences of the word "the" will be highlighted.
- The console will log whether the Translation API is detected.

## Troubleshooting

- If you see no highlights, refresh the page after loading the extension.
- Some pages restrict script injection; try a different site.
