# Mirlo Marketing Guide

## Positioning Statement

**Mirlo is a privacy-first, open-source Chrome extension that helps intermediate language learners build real fluency by reading authentic web content with instant, local translations—no tracking, no gimmicks, no upsells.**

---

## Who This Is For

### Primary Audience: The Intermediate Plateau Learner

**Profile:**
- **Language Level**: B1-B2 (Intermediate)
- **Experience**: Finished Duolingo/Babbel, can handle basic conversations, knows 1000+ words
- **Frustration**: Beginner apps feel too easy, native content feels too hard
- **Goal**: Read real articles, blogs, social media in target language
- **Values**: Privacy, authenticity, no-nonsense tools
- **Behavior**: Reads for learning, not games; wants to maintain/improve language skills

**Psychographics:**
- Self-directed learners
- Privacy-conscious
- Tired of gamification and upsell prompts
- Values open source and transparency
- Willing to put in work, just needs the right tool

### Who This Is NOT For

- ❌ Absolute beginners (learning alphabet, basic greetings)
- ❌ People wanting structured lessons with homework
- ❌ Users who need gamification to stay motivated
- ❌ Those expecting AI tutoring or conversation practice
- ❌ People looking for "learn Spanish in 30 days" shortcuts

---

## Messaging Hierarchy

### Level 1: Primary Tagline (Lead with This)
**"Privacy-first language learning for intermediate learners"**

**Usage:** Chrome Web Store title, hero sections, social media bios, GitHub README header

**Why:** Communicates our two core values (privacy + intermediate focus) in one clear statement.

---

### Level 2: Supporting Messages (Use in Pairs)

Pick 2-3 of these to support the primary tagline in any given context:

1. **"No tracking. No games. No upsells."**
   - Anti-gimmick positioning
   - Differentiates from Duolingo/Toucan
   - Use when: Emphasizing simplicity and honesty

2. **"Read real content. Build real fluency."**
   - Benefit-focused
   - Emphasizes authentic learning
   - Use when: Explaining the value proposition

3. **"For learners past the basics and ready for real fluency."**

   - Self-selecting (excludes beginners)
   - Use when: Need to clarify target audience

4. **"Open source. Free forever. Built by a learner."**
   - Trust-building
   - Emphasizes transparency and authenticity
   - Use when: Addressing skepticism or building credibility

5. **"Instant translations powered by local Chrome AI."**

   - Privacy + speed benefit
   - Use when: Explaining how it works

## Key Differentiators (vs. Competition)

### vs. Duolingo
**Their strength:** Great for beginners, gamified, structured lessons
**Our advantage:** For intermediates, real content, no games/streaks/upsells
**Message:** "You've finished Duolingo. Here's what's next."

### vs. Toucan
**Their strength:** Word-level translation while browsing
**Our advantage:** Full paragraphs, 100% local/private, open source, free
**Message:** "Toucan tracks every page you read. Mirlo doesn't."

### vs. Google Translate Extension
**Their strength:** Translates full pages
**Our advantage:** Learn as you read (not just translate), paragraph-level control
**Message:** "Translating the whole page won't help you learn. Mirlo gives you control."

### vs. ChatGPT/AI Tutors
**Their strength:** Conversational practice, explanations
**Our advantage:** Learn while doing real reading, privacy, speed, free
**Message:** "Learn from real content, not chatbots. Privacy-first. Instant."

## Messaging Do's and Don'ts

### ✅ DO:
- Lead with privacy (it's our strongest differentiator)
- Be specific about being for intermediates
- Use plain language ("no games" not "non-gamified")
- Show, don't tell (screenshots, examples)
- Be transparent about limitations (4 languages for now)
- Tell the founder story (built by a learner)
- Emphasize "open source" as trust signal

### ❌ DON'T:
- Claim it works for absolute beginners
- Overpromise on fluency timeline ("fluent in 30 days!")
- Use corporate/SaaS jargon ("leverage," "utilize," "ecosystem")
- Hide limitations or missing features
- Oversell the tech ("revolutionary AI")
- Make it sound complicated (keep it simple)
- Be negative or bitter about competitors (be confident, not petty)

## Tone & Voice

**Brand Voice Characteristics:**

1. **Honest & Direct**
   - Say what it does, not what you wish it did
   - "Works with Spanish, French, German, and English" (not "supports dozens of languages")

2. **Respectful but Real**
   - No condescension toward beginners
   - Acknowledge that different tools serve different needs
   - "Duolingo is great for beginners. Mirlo is for what comes next."

3. **Privacy-Passionate**
   - This isn't just a checkbox—it's core to who we are
   - Explain WHY privacy matters for language learning
   - "Language learning is personal. What you read is private."

4. **Learner-Empathetic**
   - Written by someone who's been there
   - Acknowledge the frustrations (plateau, lack of intermediate tools)
   - Supportive, not preachy

5. **Anti-Corporate**
   - No marketing speak
   - No fake urgency or FOMO
   - No dark patterns
   - "Built by a learner, not investors"

## Frequently Asked Questions (Messaging Guidance)

### "Is this for beginners?"
"Mirlo is designed for intermediate learners (B1-B2) who can handle basic conversations but struggle with authentic content like news articles or blogs. If you're just starting out, apps like Duolingo might be a better fit."

### "Why only 4 languages?"
"We're starting with English, Spanish, French, and German because they work reliably with Chrome's built-in translation API. We'll add more based on user feedback and testing."

### "Is it really free?"
"Yes. No premium plans, no subscriptions, no upsells. It's open source, so you can verify there are no hidden costs or data collection."

### "How is this different from Google Translate?"
"Google Translate translates entire pages, which doesn't help you learn. Mirlo lets you read naturally and click paragraphs when you need help—so you learn from context while building fluency."

### "Why should I trust this with my browsing?"
"Fair question. Mirlo is open source—you can read the code on GitHub. All translations happen locally using Chrome's built-in API. We don't have servers to send your data to, even if we wanted to."

## Success Metrics

**What "Good Messaging" Looks Like:**

1. **Self-Selection Works**
   - Beginners don't install (or uninstall quickly)
   - Intermediates feel "finally, something for me!"

2. **Privacy Resonates**
   - Users mention privacy as reason for choosing Mirlo
   - Privacy-conscious communities share it

3. **Word-of-Mouth Growth**
   - "I recommended this to my language exchange partner"
   - Organic mentions in language learning communities

4. **Quality Over Quantity**
   - Fewer but more engaged users
   - Better to have 1,000 daily users than 100,000 one-time installs
