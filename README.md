# Mirlo

**Privacy-first language learning for intermediate learners.**

Read real content with instant, local translations. No tracking, no games, no upsells.

## ✨ What Makes Mirlo Different

- **Built for Intermediates (B1-B2)**: Skip the beginner lessons. Read real news, blogs, and social media.
- **Paragraph Translation**: Understand full context. Click any paragraph for an instant translation.
- **100% Private & Local**: All translations happen on your device using Chrome's built-in AI. Zero data collection.
- **Actually Free**: No premium plans, no subscriptions. Open source on GitHub.

## 🌍 Supported Languages

Mirlo supports 4 languages that work reliably with Chrome's local translation API:

- 🇬🇧 **English**
- 🇪🇸 **Spanish**
- 🇫🇷 **French**
- 🇩🇪 **German**

*More languages coming based on user feedback!*

## 🚀 Quick Start

1.  Clone this repository.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable **Developer mode** (toggle in the top-right).
4.  Click **Load unpacked** and select the `src` folder in this project.
5.  Visit a website in one of the supported languages, click the Mirlo bird icon on any paragraph, and start learning!
