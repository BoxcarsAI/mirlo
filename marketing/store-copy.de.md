# Chrome Web Store Description (German)

## Summary (132 chars max)
Privates Sprachenlernen für Fortgeschrittene. Lesen Sie echte Inhalte mit lokalen Sofort-Übersetzungen. Kein Tracking.

## Detailed Description

Sie haben die Apps für Anfänger durchgespielt. Sie können einfache Gespräche führen. Aber wenn Sie versuchen, echte Artikel in Ihrer Zielsprache zu lesen, sind Sie verloren.

Mirlo hilft Ihnen, diese Lücke zu schließen. Lesen Sie echte Inhalte. Klicken Sie auf einen beliebigen Absatz für eine sofortige Übersetzung. Bauen Sie Sprachfluss durch authentisches Lesen auf – kein Tracking, keine Spiele, keine versteckten Kosten.

✨ Was Mirlo anders macht

• Entwickelt für Fortgeschrittene
  Überspringen Sie die Anfängerlektionen, aus denen Sie herausgewachsen sind. Lesen Sie echte Nachrichten, Blogs und soziale Medien in Ihrer Zielsprache.

• Übersetzen Sie ganze Absätze
  Verstehen Sie den vollen Kontext, nicht nur einzelne Wörter. Klicken Sie auf einen Absatz für eine sofortige Übersetzung.

• 100% privat, 100% lokal
  Alle Übersetzungen erfolgen auf Ihrem Gerät mit der integrierten KI von Chrome. Null Tracking. Null Datenerfassung. Ihr Leseverhalten bleibt privat.

• Wirklich für immer kostenlos
  Keine Premium-Pläne. Keine Upgrade-Aufforderungen. Keine Abonnements. Open Source auf GitHub – überprüfen Sie es selbst.

• Schnelle lokale Übersetzungen
  Sofortige Ergebnisse dank der lokalen KI von Chrome. Kein Warten auf API-Aufrufe.

🎯 Perfekt für

- Fortgeschrittene Sprachlerner (B1-B2), die bereit für echte Inhalte sind
- Menschen, die ihre Sprachkenntnisse durch Lesen erhalten oder verbessern
- Datenschutzbewusste Lernende, die es leid sind, getrackt zu werden
- Jeden, der von anfängerorientierten Apps frustriert ist

📚 Wie es funktioniert

1. Aktivieren Sie Mirlo auf Websites, die Sie lesen möchten
2. Wählen Sie Ihr Sprachpaar in den Einstellungen (Englisch, Spanisch, Französisch oder Deutsch)
3. Klicken Sie auf einen beliebigen Absatz, um die Übersetzung zu sehen
4. Wechseln Sie hin und her, um Ihr Verständnis zu prüfen
5. Bauen Sie echte Sprachkompetenz auf, indem Sie authentische Inhalte lesen

🔒 Datenschutzversprechen

Mirlo verwendet die integrierte Übersetzungs-API von Chrome – alles geschieht auf Ihrem Gerät. Keine externen Server. Keine Datenerfassung. Kein Tracking Ihrer Lesegewohnheiten.

Open Source Code auf GitHub verfügbar.

- Englisch ↔ Spanisch
- Englisch ↔ Französisch
- Englisch ↔ Deutsch
