📸 How to Create These Screenshots

Method 1: Replace Placeholders (Recommended)

  1. Take 4 raw screenshots of the extension in action (see suggestions below)
  2. Open this HTML file in a code editor
  3. Replace each <div class="screenshot-placeholder"> with: 
    <img src="screenshots/raw-01.png" style="width: 100%; height: 100%; object-fit: contain; border-radius: 8px;">
  4. Adjust callout positions (change top, left, right values)
  5. Use DevTools "Capture node screenshot" on each .screenshot-container
  6. Save as 01-enable-mirlo.png, 02-choose-language.png, etc.

What to Screenshot (Raw Images)

Screenshot 1: Activation Toast

  • Visit a Spanish news site (El País: elpais.com, BBC Mundo, etc.)
  • Extension should show activation toast: "Enable Mirlo on this site?"
  • Capture the whole browser window or just the article area with toast visible

Screenshot 2: Options Page

  • Open extension options (right-click icon → Options)
  • Show language dropdowns clearly
  • English → Spanish is a good default to show
  • Make sure the page looks polished (check for any dev artifacts)

Screenshot 3: Translation in Action

  • On a Spanish article, click a paragraph
  • Capture when the Mirlo tooltip is visible showing the English translation
  • Make sure the paragraph is highlighted/selected
  • Pick an interesting article (not Lorem Ipsum!)
  • Bonus: Use El País or a well-known Spanish publication for credibility

Screenshot 4: Toggle Feature

  • With a paragraph already translated, click it again
  • Show the tooltip with "Switch to Spanish" button
  • This demonstrates the toggle/test-yourself feature

Pro Tips

  • Use real content: El País, BBC Mundo, Wikipedia ES—not test pages
  • Pick interesting headlines: "Madrid celebra..." is better than "Lorem ipsum..."
  • Clean browser: Close extra tabs, use a clean Chrome profile
  • Consistent zoom: Keep browser at 100% zoom for all screenshots
  • Professional sites: Well-known publications look more credible
  • Good lighting: If you screenshot your screen, ensure even lighting (or just use DevTools capture)

Quick Alternative: Simple Screenshots

If the framed approach feels too complex, you can also submit simple, clean screenshots of the extension in use at 1280x800px. Chrome Web Store accepts both annotated and clean screenshots. The frames just add polish and guide the viewer's eye.
