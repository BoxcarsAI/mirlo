# Chrome Web Store Description (French)

## Summary (132 chars max)
Apprentissage privé pour niveau intermédiaire. Lisez du vrai contenu avec traductions locales instantanées. Sans suivi.

## Detailed Description

Vous avez terminé les applications pour débutants. Vous pouvez tenir des conversations de base. Mais lorsque vous essayez de lire de vrais articles dans la langue cible, vous êtes perdu.

Mirlo vous aide à combler cet écart. Lisez du contenu réel. Cliquez sur n'importe quel paragraphe pour une traduction instantanée. Développez votre fluidité grâce à une lecture authentique : pas de suivi, pas de jeux, pas de ventes incitatives.

✨ Ce qui rend Mirlo différent

• Conçu pour les apprenants intermédiaires
  Passez les leçons pour débutants que vous avez dépassées. Lisez de vraies actualités, blogs et réseaux sociaux dans votre langue cible.

• Traduisez des paragraphes entiers
  Comprenez le contexte complet, pas seulement des mots isolés. Cliquez sur n'importe quel paragraphe pour une traduction instantanée.

• 100 % privé, 100 % local
  Toutes les traductions se font sur votre appareil grâce à l'IA intégrée de Chrome. Zéro suivi. Zéro collecte de données. Votre lecture est privée.

• Vraiment gratuit pour toujours
  Pas de forfaits premium. Pas d'invites de mise à niveau. Pas d'abonnements. Open source sur GitHub — vérifiez par vous-même.

• Traductions locales rapides
  Résultats instantanés propulsés par l'IA locale de Chrome. Pas d'attente pour des appels API.

🎯 Parfait pour

- Les apprenants de niveau intermédiaire (B1-B2) prêts pour du contenu réel
- Les personnes qui maintiennent ou améliorent leurs compétences linguistiques par la lecture
- Les apprenants soucieux de leur vie privée et fatigués d'être suivis
- Toute personne frustrée par les applications axées sur les débutants

📚 Comment ça marche

1. Activez Mirlo sur les sites web que vous souhaitez lire
2. Choisissez votre paire de langues dans les paramètres (Anglais, Espagnol, Français ou Allemand)
3. Cliquez sur n'importe quel paragraphe pour voir la traduction
4. Basculez de l'un à l'autre pour vérifier votre compréhension
5. Développez une vraie fluidité en lisant du contenu authentique

🔒 Promesse de confidentialité

Mirlo utilise l'API de traduction intégrée de Chrome : tout se passe sur votre appareil. Pas de serveurs externes. Pas de collecte de données. Pas de suivi de vos habitudes de lecture.

Code open source disponible sur GitHub.

🌍 Langues prises en charge

- Anglais ↔ Espagnol
- Anglais ↔ Français
- Anglais ↔ Allemand

Nous commençons avec les langues qui fonctionnent de manière fiable avec l'API de traduction locale de Chrome. D'autres langues viendront en fonction des retours des utilisateurs.
