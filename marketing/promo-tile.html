📸 How to create your promo tile:

  1. Open this file in Chrome (it should already be open)
  2. Right-click on the colored tile → Inspect
  3. In DevTools Elements panel, find <div class="promo-tile">
  4. Right-click on it → "Capture node screenshot"
  5. Save as promo-tile-440x280.png in this marketing folder

Alternative: Use macOS Screenshot (Cmd+Shift+4) and carefully select just the colored tile.
