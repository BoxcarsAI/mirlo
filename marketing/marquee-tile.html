📸 How to create your marquee tile (1400x560px):

  1. This file should already be open in Chrome
  2. Right-click on the colored tile → Inspect
  3. In DevTools Elements panel, find <div class="marquee-tile">
  4. Right-click on it → "Capture node screenshot"
  5. Save as marquee-tile-1400x560.png in the marketing folder
  6. Convert to JPEG (Chrome Store requirement):
    • Open PNG in Preview/Photoshop
    • Export as JPEG (quality 90-95%)
    • Or use: sips -s format jpeg marquee-tile-1400x560.png --out marquee-tile-1400x560.jpg

Note: Chrome Web Store requires JPEG or 24-bit PNG (no alpha/transparency). JPEG is recommended for this size.

Alternative: Use macOS Screenshot (Cmd+Shift+4) and carefully select the entire tile.
